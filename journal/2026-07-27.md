# 2026-07-27 — XML Validation Fix Advanced While Mainline Dependencies Moved

## Embedded XML Validation
- Community E2E coverage opened issue [#407](https://github.com/clawosiris/rust-gvm/issues/407) after `import_report_format` rejected a valid document containing a nested self-closing element followed by a sibling.
- The root cause is in `validate_single_xml_document`, which incorrectly marks every empty element as a completed top-level root even when it is nested.
- PR [#410](https://github.com/clawosiris/rust-gvm/pull/410) now fixes the depth handling and adds validator and public API regression coverage; all required CI and security checks are green, with review approval still required before it can merge into `devel`.
