## Rationale / Notes
- python-gvm two-connection flow is critical: connection 1 probes version, connection 2 authenticates. Mock server handles this via per-session auth state.
- Codex struggles with cargo-deny schema changes and rustfmt nightly options — these required manual iteration.
- Static musl builds are ideal for CI consumption by downstream projects (no shared lib deps).
- cargo-deny v2 removed many fields (`unlicensed`, `copyleft`, `vulnerability`, `unmaintained`, `yanked`, `notice`) — the migration took 3 commits to get right.
